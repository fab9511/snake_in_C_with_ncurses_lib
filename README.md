# 🐍 Snake in C with ncurses

Klasyczna gra **Snake** napisana w **języku C**, działająca w terminalu przy użyciu biblioteki **ncurses**.

---

## 📌 Opis projektu

Projekt implementuje prostą wersję gry Snake uruchamianą w terminalu.  
Gracz steruje wężem, który porusza się po planszy, zbiera jedzenie i rośnie.  
Gra kończy się po kolizji ze ścianą lub własnym ciałem.

Do obsługi:
- rysowania planszy,
- wejścia z klawiatury,
- animacji,

wykorzystana jest biblioteka **ncurses**.

---

## 🛠️ Wymagania

- Kompilator C (np. `gcc`)
- Biblioteka `ncurses`
